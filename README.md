## featured projects

### 🌿 [EcoShop](https://github.com/maria-brito15/ecoshop-nextjs) — Sustainable E-Commerce Platform `🏆 PUC Minas Finalist`

A full-stack e-commerce/catalog platform for eco-friendly products with an **AI-powered material scanner**. Born as a finalist academic project and completely rewritten solo to consolidate learning with a modern stack.

**v1 · Original (2025) — Java + Spark Framework**
> Academic version selected among the semester's best projects. Classic MVC architecture with Controller → Service → DAO layers, direct PostgreSQL via JDBC, manual XSS input sanitization, BCrypt session auth, JUnit 5 + Mockito tests, Docker deploy on Render.

`Java` `Spark Framework` `PostgreSQL` `JDBC` `BCrypt` `JUnit 5` `Mockito` `Docker`

**v2 · Refactor (2026) — Next.js 15 + TypeScript**
> Full solo rewrite with a modern stack. App Router, two-layer cache (Redis + Map stale-while-revalidate), typed Prisma ORM, stateless JWT with centralized middleware and Zod validation on every route.

- **AI with distinct responsibilities:** a model I trained on Azure Custom Vision identifies recyclable materials from images; Gemini 2.0 Flash generates sustainability analyses — each integration solves a different part of the product problem
- **Resilience:** graceful degradation if either AI service is unavailable
- Two-layer cache: **Redis** (server) + `Map` stale-while-revalidate (client)
- Role-based access control: `ADMIN`, `CLIENTE`, `MARCA`
- CI/CD with GitHub Actions + GitHub Container Registry (lint, type-check, build, deploy via SSH)

`Next.js 15` `TypeScript 5` `Prisma 7` `PostgreSQL` `Redis 4` `JWT / jose` `Zod 3` `React 19` `Tailwind CSS 4` `Azure Custom Vision` `Gemini 2.0 Flash` `Docker` `GitHub Actions`

**v3 · SDD Refactor (2026 – in progress)**
> Refactoring the project with **Specification-Driven Development**: specifications guide planning, implementation and validation of every change, and also organize how the two AI integrations are maintained.

### ♻️ [Reciclaki](https://github.com/maria-brito15/plf-es-2026-2-ti2-7587100-reciclaki) — Selective Collection & Recycling Platform `👥 Team of 7`

An evolution of a selective-collection support system in Belo Horizonte: citizens find where to dispose of each material and earn points redeemable for rewards. Built for the Interdisciplinary Project (Software Engineering, PUC Minas), Oct–Nov 2026.

- Scope redefined through qualitative interviews: the data model went from **17 to 11 collections**, with three profiles (citizen, waste picker, manager) — decisions recorded in a **single specification used as source of truth**
- Collection-point map with geospatial queries (`2dsphere` index), react-leaflet and OpenStreetMap
- Points calculation, reward redemption, cooperative pick-ups and a community reporting module
- JWT in httpOnly cookie (jose), role-based access via middleware, Zod validation
- **400+ automated tests** with Vitest and Testing Library (services, routes, scoring rules, components)

`Next.js` `TypeScript` `React` `Tailwind CSS` `TanStack Query` `Zod` `MongoDB Atlas` `RESTHeart` `Vercel` `Vitest` `GitHub Actions`

### 🔌 WhatsApp Dispatcher — Mass Messaging System `Case Study`

An **architecture case study** (partial implementation) exploring how a reliable WhatsApp mass-messaging system could be designed for campaigns and automated flows.

The study covers **Domain-Driven Design, Clean Architecture, Hexagonal Architecture, asynchronous processing with queues and workers (BullMQ + Redis), idempotency, retries with backoff, fault tolerance, distributed locking, and system reliability**, focusing on the reasoning behind the architectural decisions and their trade-offs.

[→ Read the Case Study](https://mariabdev.netlify.app/cases/whatsapp-dispatcher)

### 🔗 [ShortURL](https://github.com/maria-brito15/shorturl-express) — URL Shortener with Click Analytics

A production-ready URL shortener with a **Redis caching layer** for sub-millisecond redirects and atomic click tracking.

**Highlights:**
- Redis cache with 10-minute TTL — cache-miss falls back to MongoDB and repopulates automatically
- Atomic click counter incremented asynchronously on every redirect
- Zod validation middleware rejects malformed URLs before reaching the controller
- REST API + static frontend served from the same Express server
- Full Docker Compose setup: one command spins up the API, MongoDB and Redis

`Node.js 20` `TypeScript 5` `Express` `MongoDB` `Redis` `Zod` `Docker` `GitHub Actions`
