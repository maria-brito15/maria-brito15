## projetos em destaque

### 🌿 [EcoShop](https://github.com/maria-brito15/ecoshop-nextjs) — Plataforma de E-Commerce Sustentável `🏆 Finalista PUC Minas`

Uma plataforma full-stack de e-commerce/catálogo de produtos ecológicos com um **scanner de materiais com IA**. Nasceu como projeto acadêmico finalista e foi completamente reescrita sozinha para consolidar o aprendizado com uma stack moderna.

**v1 · Original (2025) — Java + Spark Framework**
> Versão acadêmica selecionada entre os melhores projetos do semestre. Arquitetura MVC clássica com camadas Controller → Service → DAO, conexão direta com PostgreSQL via JDBC, sanitização manual de entrada contra XSS, autenticação por sessão com BCrypt, testes com JUnit 5 + Mockito, deploy com Docker no Render.

`Java` `Spark Framework` `PostgreSQL` `JDBC` `BCrypt` `JUnit 5` `Mockito` `Docker` `Azure Vision` `Gemini API`

**v2 · Refatoração (2026) — Next.js 15 + TypeScript**
> Reescrita completa e solo com uma stack moderna. App Router, cache em duas camadas (Redis + Map stale-while-revalidate), ORM Prisma tipado, JWT stateless com middleware centralizado e validação Zod em todas as rotas.

- Cache em duas camadas: **Redis** (servidor) + `Map` stale-while-revalidate (cliente)
- Scanner com IA: Azure Custom Vision + Gemini 2.0 Flash — com degradação graciosa caso um dos serviços fique indisponível
- Controle de acesso por papéis: `ADMIN`, `CLIENTE`, `MARCA`
- CI/CD com GitHub Actions + GitHub Container Registry (lint, type-check, build, deploy via SSH)

`Next.js 15` `TypeScript 5` `Prisma 7` `PostgreSQL` `Redis 4` `JWT / jose` `Zod 3` `React 19` `Tailwind CSS 4` `Azure Custom Vision` `Gemini 2.0 Flash` `Docker` `GitHub Actions`

### 🔌 [WhatsApp Dispatcher](https://github.com/maria-brito15/whatsapp-dispatcher) — Sistema de Disparo de Mensagens `em desenvolvimento`

Um dispatcher de mensagens de alta performance para campanhas e fluxos no WhatsApp, construído do zero para estudar arquitetura e confiabilidade a sério — **Domain-Driven Design**, **Clean Architecture** e uma estrutura inspirada em arquitetura hexagonal, mantendo a lógica de negócio independente da infraestrutura.

**O que torna diferente:**
- **Scheduler + Workers:** BullMQ lida com milhões de mensagens com retries, backoff e controle de concorrência
- **Reconciliação em duas etapas:** recupera jobs travados e reativa fluxos que falharam automaticamente
- **Camada de cache:** Redis para contagens de status rápidas e menos carga no banco
- **Trilha de auditoria completa:** toda ação enviada, falha, pausada ou concluída é registrada
- **Soft deletes & versionamento:** retenção segura de dados para ambientes de produção

`Node.js 20` `TypeScript 5` `Prisma 7` `PostgreSQL` `Redis 4` `BullMQ` `Docker` `Zod` `JWT` `DDD` `Clean Architecture`

### 🔗 [ShortURL](https://github.com/maria-brito15/shorturl-express) — Encurtador de URLs com Analytics de Cliques

Um encurtador de URLs pronto para produção com uma **camada de cache Redis** para redirecionamentos em submilissegundos e rastreamento atômico de cliques.

**Destaques:**
- Cache Redis com TTL de 10 minutos — cache-miss cai para o MongoDB e repopula automaticamente
- Contador de cliques atômico, incrementado de forma assíncrona a cada redirecionamento
- Middleware de validação com Zod rejeita URLs malformadas antes de chegar ao controller
- API REST + frontend estático servidos pelo mesmo servidor Express
- Setup completo com Docker Compose: um comando sobe API, MongoDB e Redis

`Node.js 20` `TypeScript 5` `Express` `MongoDB` `Redis` `Zod` `Docker` `GitHub Actions`
